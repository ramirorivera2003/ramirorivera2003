## 03 // Active Missions

### SafetyAccess — AI-Powered PPE Verification

A computer vision project designed to check whether people are wearing required personal protective equipment before entering a restricted area. It combines YOLO-based detection, a desktop interface, event logging, and Arduino-based physical access control.

**Stack:** `Python` `YOLO` `OpenCV` `PySide6` `Arduino` `SQLite`

### El Dragón POS — Point of Sale System

A point-of-sale application for a small food business, developed to handle products, customizable orders, sales, and operational workflows. Built from practical needs and improved through iteration.

**Stack:** `Python` `Django` `SQLite` `HTML` `CSS`
